# Reflexión sobre Obsidian y GitHub

Durante el desarrollo de esta actividad pude comprender la utilidad de Obsidian y GitHub para la gestión del conocimiento. Obsidian permitió organizar conceptos mediante notas conectadas entre sí, facilitando la comprensión de los contenidos y la creación de relaciones entre distintos temas de visualización de datos.

Por otra parte, GitHub permitió almacenar el trabajo realizado y mantener un registro de los cambios efectuados durante el proceso. Gracias al sistema de commits es posible visualizar el avance del proyecto y conservar diferentes versiones de los archivos.

Considero que ambas herramientas son complementarias, ya que Obsidian facilita la organización del conocimiento y GitHub aporta control de versiones, respaldo y trazabilidad. Estas características resultan especialmente útiles en proyectos relacionados con ciencia de datos, análisis de información y trabajo colaborativo.

La experiencia permitió desarrollar habilidades de organización, documentación y gestión de información, competencias fundamentales para futuros proyectos académicos y profesionales.
